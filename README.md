# Smart Insurance Mobile App

A modern, responsive Mobile Operating System & Insurance Multi-App Dashboard built using **HTML5, CSS3, and JavaScript (Vanilla)**.

## 📱 Features

- **Mobile OS Launcher & App Switcher:**
  - Realistic Android / iOS app launcher home screen with clock, weather, search pill, and app icons.
  - Multi-tasking 3D Card Carousel (Recents overview inspired by Android app switcher).
  - Instant app-to-app switching (e.g. from Claims to Investment).
  - Single-click **"Close all"** button and background app memory management.
  - Native 3-button system navigation bar (Recents `|||`, Home `○`, Back `<`).

- **Core Business Mini-Apps:**
  1. **Claim Management:** Intimate & track hospital cashless, motor accident, and death claims.
  2. **Investment & Mutual Funds:** AUM tracking (₹3.85 Cr), active SIP book, top fund portfolios, e-Mandate generator.
  3. **Life Insurance:** Term Life, Endowment, and ULIP policy portfolio with renewal alerts.
  4. **General Insurance:** Health mediclaim, private car, two-wheeler, and commercial fire insurance.
  5. **Client CRM:** 1,428 clients directory, HNI/Retail segmentation, direct WhatsApp & Call actions.
  6. **Commission Tracker:** First-year commission (FYC), Renewal commission (RC), Sub-agent bonuses, TDS deduction & payout slips.
  7. **Reports & MIS:** Yearly MDRT target progress (78% achieved), business MIS, lapse register.
  8. **Document Vault:** Digital repository for 915 policy bonds and verified KYC documents.
  9. **Smart Digital Connect:** Automated WhatsApp payment reminder links & festive greetings.
  10. **Sub-Agent Network:** 16 POSP agents hierarchy and team performance tracking.

## 🛠️ Tech Stack

- **HTML5:** Semantic architecture, multi-window application stage.
- **CSS3:** Modern CSS variables, glassmorphism, responsive viewport scaling, 3D transform card switcher.
- **JavaScript (ES6):** State-driven multitasking engine, real-time clock, interactive modals and forms.

## 🚀 How to Run

Simply open `index.html` in any web browser or deploy directly to GitHub Pages:
```bash
# Clone the repository
git clone https://github.com/reach-bhavesh/mobile-app.git

# Open index.html in your browser
```
